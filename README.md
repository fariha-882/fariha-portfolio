# Fariha Islam — Personal Portfolio

A responsive, animated personal portfolio website for Fariha Islam, a CSE student at Daffodil International University.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Folder structure

```text
fariha-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    └── profile.jpg
```

## Before publishing

1. Replace the project placeholders in `index.html` with your real project details.
2. Add your Instagram URL where the Instagram placeholder is used.
3. Add project screenshots if you want them.
4. Check all links.
5. Push the folder to GitHub.

## Git commands

```bash
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/fariha-882/fariha-portfolio.git
git push -u origin main
```

## GitHub Pages

In GitHub:

`Repository → Settings → Pages`

Choose deployment from the `main` branch and the `/root` folder, then save.

The site will be available at:

`https://fariha-882.github.io/fariha-portfolio/`

The exact URL depends on the repository name.
